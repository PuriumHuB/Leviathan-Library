# 📖 Overview

Leviathan UI is a heavily modified and expanded fork of Wind UI.

The goal of Leviathan is not to replace Wind UI, but to build upon its strong foundation by introducing:

- Expanded theme support
- Reworked components
- Improved visual consistency
- Better theme synchronization
- Enhanced animations
- Additional customization
- Quality-of-life improvements

Leviathan aims to preserve the simplicity and usability of Wind UI while exploring new ideas and improvements.
